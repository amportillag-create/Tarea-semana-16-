## Descripción

Restaurante App es un sistema desarrollado en Python utilizando Programación Orientada a Objetos (POO). El proyecto permite gestionar productos, usuarios y ventas mediante una interfaz gráfica desarrollada con Tkinter.

El sistema ha ido evolucionando durante las diferentes semanas de trabajo. En esta etapa se incorporó el manejo de eventos en la interfaz gráfica y la gestión administrativa de usuarios mediante operaciones CRUD.

## Objetivo

Desarrollar una aplicación gráfica para la gestión básica de un restaurante, aplicando programación orientada a objetos, manejo de eventos, estructuras de datos y almacenamiento de información mediante archivos JSON.

## Tecnologías utilizadas

- Python
- Tkinter
- Programación Orientada a Objetos
- JSON
- Visual Studio Code
- Git y GitHub
